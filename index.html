Features

Lists and segments

Single and double opt-in lists with millions of subscribers. Find and save groups of subscribers from conditions, with no SQL, or write SQL when you need to.

Signup forms

Build a form once and share it as a hosted page, an embed for your website, or a popup, with signup figures and bot protection.

Campaigns that reach the inbox

A visual builder, rich text, Markdown or raw HTML. Before you send, an inbox check flags what tends to land in spam, and campaigns can't go out without an unsubscribe link.

Analytics and replies

Opens, clicks and bounces across campaigns. Track replies too: see who answered, with every reply forwarded to your inbox.

Transactional email for developers

Scoped API keys, templates with live preview, a message log, webhooks and email branding. The quickstart gives you working code in curl, Node, Python or Go, or a prompt for your AI assistant.

Templating

Dynamic templates with the Go templating language: expressions, logic and 100+ functions in subject lines and content.

Clean lists

Guided import with a dry run before anything is written, bounce handling, email validation, and scheduled cleanup of subscribers who never open.

Teams and privacy

Roles and per-list permissions, single sign-on, required two-step verification, and full privacy controls for subscribers.

Self-host

listnun is free and open source. Run it on your own server with Docker, or build it from source. See the releases.


Docker

ghcr.io/nerd-zero/listnun:latest

Download and use the sample docker-compose.yml:

# Download the compose file to the current directory.
curl -LO https://github.com/nerd-zero/listnun/raw/master/docker-compose.yml

# Run the services in the background.
docker compose up -d

Visit http://localhost:9000

Installation docs →

From source

Build the binary, then:

  • ./listnun --new-config to generate config.toml. Edit it.
  • ./listnun --install to set up the Postgres database, or --upgrade to upgrade an existing one.
  • Run ./listnun and visit http://localhost:9000
